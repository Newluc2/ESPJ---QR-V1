Système de Pointage QR Code - Setup Assistant

🔑 Étape 1: Configuration Google Cloud (CRITIQUE!)

⚠️ ATTENTION: Cette étape DOIT être complétée en premier! Sans cela, l'application ne fonctionnera pas.
1

Google Cloud Project

Créez un nouveau projet

  1. Allez sur: https://console.cloud.google.com/
  2. Cliquez "Créer un projet"
  3. Nommez-le "Pointage QR Code"
  4. Cliquez "Créer"
2

Google Sheets API

Activez l'API Sheets

  1. Cherchez "Google Sheets API"
  2. Cliquez "ACTIVER"
  3. Attendez l'activation
3

Service Account

Créez un Service Account

  1. Allez à: APIs & Services → Credentials
  2. Cliquez "+ CREATE CREDENTIALS"
  3. Sélectionnez "Service Account"
  4. Remplissez: Name = "pointage-app"
4

JSON Credentials

Téléchargez les credentials

  1. Allez dans "KEYS"
  2. Cliquez "CREATE new key"
  3. Sélectionnez "JSON"
  4. Cliquez "CREATE"
5

Google Sheet

Créez un nouveau Sheet

  1. Allez sur: https://sheets.google.com/
  2. Cliquez "+"
  3. Nommez-le "Pointage Système QR Code"
6

Partage

Partagez le Sheet

  1. Cliquez "Partager"
  2. Collez l'email du Service Account
  3. Donnez la permission "Editeur"
  4. Cliquez "Partager"
✅ Continuez quand vous avez:
  • ✓ Le fichier JSON téléchargé
  • ✓ Extrait client_email et private_key
  • ✓ Le GOOGLE_SHEET_ID copié
  • ✓ Le Sheet partagé avec le Service Account
